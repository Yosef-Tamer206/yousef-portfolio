# Yousef Tamer — Portfolio website

A playful, arcade-themed personal portfolio. Pure HTML/CSS/JS: no build step, no dependencies.

## Run it
Open `index.html` in any browser. Or serve the folder:
```
python3 -m http.server 8000
# then visit http://localhost:8000
```

## What's inside
- `index.html` — all sections: hero, Power-ups (skills), The arcade (6 projects with live demos), Bug catcher (mini-game), Out in the wild (event photos), Player card (about), Insert coin (contact).
- `style.css` — neo-brutalist arcade styling, responsive down to small phones.
- `app.js` — hero word rotator, the Bug catcher game, copy-email button.
- `assets/` — portrait, event photos, and screenshots of the six live projects.

Everything is self-contained except the Google Fonts link (falls back to system fonts offline).
